
ഗിറ്റ് (Git) ഒരു ഫയലിൽ വരുത്തുന്ന മാറ്റങ്ങൾ ട്രാക്ക് ചെയ്യുന്നത് അതിന്റെ ഉള്ളടക്കത്തിന്റെ സ്നാപ്പ്ഷോട്ടുകൾ (snapshots) എടുത്താണ്; ഇതിനെ 'വേർഷൻ കൺട്രോൾ' (Version Control) എന്ന് വിളിക്കുന്നു. നിങ്ങൾ ഒരു ഫയലിൽ മാറ്റം വരുത്തുമ്പോൾ, ഗിറ്റ് അതിലെ വരികൾ ഒത്തുനോക്കി ഏതൊക്കെ ഭാഗങ്ങളാണ് കൂട്ടിച്ചേർത്തതെന്നും (additions) ഒഴിവാക്കിയതെന്നും (deletions) കൃത്യമായി കണ്ടെത്തുന്നു. ഈ മാറ്റങ്ങൾ പിന്നീട് 'git commit' ചെയ്യുന്നതിലൂടെ ഫയലിന്റെ മുൻപത്തെ പതിപ്പുമായി താരതമ്യം ചെയ്യാനും അതിന്റെ ചരിത്രം സുരക്ഷിതമായി സൂക്ഷിക്കാനും സാധിക്കുന്നു.
