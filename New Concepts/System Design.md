
## What is System Design 


നമ്മൾ കോളേജിൽ personal projects ചെയ്യുമ്പോൾ കുറച് users എ ഉണ്ടാവുള്ളു. എന്നാൽ Real-world ആളുകൾ വരുമ്പോൾ (അതായത് ലക്ഷകണക്കിന് അല്ലെങ്കിൽ കോടികണക്കിന് ആളുകൾ ) ഉപയോഗിക്കുന്ന application ഉണ്ടാക്കുമ്പോൾ നമ്മൾ കുറച്ച് കാര്യങ്ങൾ ശ്രദ്ധിക്കാൻ ഉണ്ട്.

- Scale ചെയ്യണം
- Fault Tolerance (അതായത് ഒരു system fail ആവാതെ നോക്കാൻ വേണ്ടി ഉപയോഗിക്കുന്ന മാർഗങ്ങൾ )
- ==**security==** (അതായത് ഒരു application ന്റെ തുടക്കത്തിൽ തന്നെ security define ചെയ്യുന്നതിലൂടെ ആ application ന്റെ സുരക്ഷാ വർധിപ്പിക്കുന്നു )
- Monitering (ഇതുകൊണ്ട് ഉദ്ദേശിച്ചത് servers health ,performance ,infrastructure ന്റെ availability , application realtime ൽ data-collection and alerts.
- ഏത് സാഹചര്യത്തിലും അപ്ലിക്കേഷൻ reliable ആയും stable ആയും പ്രവർത്തിക്കുന്നു എന്ന് ഉറപ്പ് വരുത്തുന്നു .)
