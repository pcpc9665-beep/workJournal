**Zustand** (German for "state") is ==🔴a small, fast, and scalable state management library primarily used in React and React Native applications==

## Features : 
Key Features

- **Minimal Boilerplate:** You can create a global store using a single hook without writing complex actions, reducers, or dispatchers. [[1](https://medium.com/globant/react-state-management-b0c81e0cbbf3), [2](https://zustand.docs.pmnd.rs/)]
- **No Provider Required:** Unlike Context API or Redux, Zustand does not require wrapping your component tree in provider components. [[1](https://refine.dev/blog/zustand-react-state/), [2](https://dev.to/ajmal_hasan/simplifying-state-management-in-react-native-with-zustand-41f2)]
- **Hooks-Based API:** Components read and update state directly through custom hooks, preventing unnecessary re-renders with selector support. [[1](https://zustand.docs.pmnd.rs/), [2](https://blog.logrocket.com/zustand-adoption-guide/), [3](https://medium.com/stackanatomy/zustand-simple-modern-state-management-for-react-242bc5ab13db)]
- **Vanilla JavaScript Support:** You can access and modify the store outside of React components because the state lives outside the React tree. [[1](https://blog.logrocket.com/managing-react-state-zustand/), [2](https://zustand.docs.pmnd.rs/)]
- **Built-in Middleware:** Supports tools like Redux DevTools, local storage persistence, Immer for immutable updates, and TypeScript typing out of the box. [[1](https://zustand.docs.pmnd.rs/), [2](https://github.com/pmndrs/zustand)]
